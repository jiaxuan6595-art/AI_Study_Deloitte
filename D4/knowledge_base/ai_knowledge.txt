人工智能（Artificial Intelligence，简称AI）

人工智能是计算机科学的一个分支，旨在开发能够模拟人类智能的系统和技术。AI的核心目标是让计算机能够执行通常需要人类智能才能完成的任务，如视觉感知、语音识别、决策制定和自然语言处理。

AI的主要分支包括：
1. 机器学习（Machine Learning）：让计算机从数据中学习规律和模式，而不需要显式编程。
2. 深度学习（Deep Learning）：使用多层神经网络处理复杂数据，是机器学习的一个子集。
3. 自然语言处理（Natural Language Processing，NLP）：让计算机理解和生成人类语言。
4. 计算机视觉（Computer Vision）：让计算机理解和处理图像和视频。
5. 机器人学（Robotics）：让机器人能够感知环境并做出决策。

---

机器学习（Machine Learning）

机器学习是人工智能的核心技术之一。它让计算机能够从数据中自动学习规律和模式，并利用这些规律进行预测和决策，而不需要人为编写具体的规则。

机器学习的三种主要类型：
1. 监督学习（Supervised Learning）：使用带标签的数据进行训练。模型学习输入和输出之间的映射关系。常见应用包括图像分类、垃圾邮件检测、房价预测等。
2. 无监督学习（Unsupervised Learning）：使用无标签的数据进行训练。模型自动发现数据中的结构和模式。常见应用包括客户分群、异常检测、数据降维等。
3. 强化学习（Reinforcement Learning）：通过与环境交互来学习。模型根据行为获得的奖励或惩罚来调整策略。常见应用包括游戏AI、自动驾驶、机器人控制等。

机器学习的工作流程通常包括：数据收集 → 数据预处理 → 特征工程 → 模型选择 → 模型训练 → 模型评估 → 模型部署。

深度学习（Deep Learning）

深度学习是机器学习的一个子领域，通过多层神经网络来学习数据的层次化表示。"深度"指的是神经网络的层数较多，通常有数十层甚至上百层。

常见的深度学习模型架构：
1. 卷积神经网络（CNN）：擅长处理图像数据，广泛应用于图像分类、目标检测、人脸识别等领域。
2. 循环神经网络（RNN）：擅长处理序列数据，如文本、语音、时间序列等。LSTM和GRU是RNN的改进版本。
3. Transformer：基于自注意力机制的架构，是当前大语言模型（LLM）的基础。GPT、BERT、LLaMA等模型都基于Transformer。
4. 生成对抗网络（GAN）：由生成器和判别器组成，用于生成逼真的图像、视频等。

深度学习的应用场景：
- 图像识别：人脸识别、医学影像诊断、自动驾驶感知
- 语音处理：语音识别、语音合成、声纹识别
- 自然语言处理：机器翻译、文本摘要、对话系统
- 推荐系统：电商推荐、内容推荐、广告投放

自然语言处理（Natural Language Processing，NLP）

自然语言处理是人工智能中研究计算机与人类语言交互的领域。NLP的目标是让计算机能够理解、解释和生成人类语言。

NLP的主要任务：
1. 文本分类：将文本归类到预定义的类别中，如情感分析、垃圾邮件检测、新闻分类。
2. 命名实体识别（NER）：从文本中识别出人名、地名、组织名等实体。
3. 机器翻译：将一种语言自动翻译为另一种语言，如中英翻译。
4. 文本摘要：将长文本自动压缩为简短的摘要。
5. 问答系统：根据用户的问题，从知识库或文档中找到答案。
6. 对话系统：与用户进行自然语言对话，如智能客服、虚拟助手。

NLP的发展历程：
- 规则方法（1950s-1980s）：基于人工编写的语法规则
- 统计方法（1990s-2010s）：基于统计模型和机器学习
- 深度学习方法（2010s至今）：基于神经网络，特别是Transformer架构

当前NLP的核心技术是大语言模型（LLM），如GPT系列、BERT、通义千问等。这些模型通过在海量文本上预训练，获得了强大的语言理解和生成能力。

阿里云百炼平台

阿里云百炼（DashScope）是阿里云推出的大模型服务平台，提供多种AI模型的API调用服务。

支持的模型类型：
1. 对话模型：qwen-turbo、qwen-plus、qwen-max等通义千问系列模型
2. 嵌入模型：text-embedding-v3（最新版，支持1024/768/512维度）、text-embedding-v2（1536维度）
3. 图像模型：通义万相等图像生成模型
4. 语音模型：语音识别和语音合成模型

百炼平台的使用方式：
- API兼容OpenAI接口格式，可以使用OpenAI SDK直接调用
- 基础URL：https://dashscope.aliyuncs.com/compatible-mode/v1
- 支持流式输出、函数调用、结构化输出等高级功能

嵌入模型的使用场景：
- 文本相似度计算：判断两段文本的语义相似程度
- 语义搜索：根据查询的语义而非关键词匹配来搜索文档
- 文本聚类：将语义相近的文本自动分组
- RAG（检索增强生成）：将文档嵌入向量存储，检索相关片段辅助LLM生成回答

向量数据库与RAG

向量数据库是专门存储和检索高维向量的数据库系统。在AI应用中，向量数据库主要用于存储文本的嵌入向量，并支持高效的相似度搜索。

常见的向量数据库：
1. ChromaDB：轻量级开源向量数据库，适合开发和原型验证
2. Milvus：高性能分布式向量数据库，适合大规模生产环境
3. Pinecone：云端托管的向量数据库服务
4. FAISS：Facebook开源的向量检索库，适合本地高效检索

RAG（Retrieval-Augmented Generation，检索增强生成）是一种将检索和生成结合的技术框架。RAG的工作流程：
1. 文档处理：加载文档 → 切分为片段 → 嵌入为向量 → 存入向量数据库
2. 查询处理：用户提问 → 问题嵌入为向量 → 在向量数据库中检索最相关的文档片段
3. 回答生成：将检索到的文档片段作为上下文拼入Prompt → LLM基于上下文生成回答

RAG的优势：
- 知识实时性：可以随时更新知识库，无需重新训练模型
- 回答可溯源：回答基于具体文档，可以追溯来源
- 减少幻觉：基于真实文档回答，降低编造信息的风险
- 成本低：不需要训练或微调大模型
